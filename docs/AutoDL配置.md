# 在 AutoDL 上出片

## 第一次使用

1. 安装后第一次打开黑箱剧场，会先进入配置向导，选择「租用云 GPU（AutoDL）」。选了「稍后再说」的话，以后可以在「设置 → 远程 GPU」点「连接 AutoDL 实例」打开同样的步骤。
2. 点击「打开 AutoDL 控制台」，用自己的账号租用并启动 Linux GPU 实例。将控制台里的整条 SSH 登录指令与实例密码分别粘贴到软件对应的输入框。Windows 独立安装包已内置 SSH 客户端。从源码运行时，使用系统的 OpenSSH 客户端。
3. 点击「注册并创建 API Key」，在 DeepSeek 开放平台获取密钥，粘贴到 DeepSeek API Key 栏。软件向 DeepSeek 验证密钥，并使用系统加密功能保存在本机。实例密码只在首次 SSH 登录时使用。软件登记本机专用公钥，后续连接可留空密码。
4. 选择工作流，点击「开始配置并自检」。软件会选中该服务器、上传安装包，并在「设置 → 远程 GPU」的「云端配置」里显示进度。该页显示当前阶段、已缓存和已下载的模型数据量、近期传输速度和预计下载完成的本机时间。
5. 可调整给环境安装和验收预留的分钟数，再点「打开 AutoDL 控制台安排关机」。预留时长由用户决定，设置定时关机需在控制台确认。收到「自检通过」并看见验收素材后，保持实例开机，选择或新建剧本项目，即可开始使用本次安装的功能。

## 先用无卡模式下载模型（省钱）

整套模型约 66 GiB，下载可能要几个小时。下载不需要显卡，没必要开着 GPU 等。AutoDL 实例可以在控制台选「无卡模式开机」：没有 GPU，按很低的价格计费，数据盘和有卡模式是同一块。

1. 在 AutoDL 控制台用「无卡模式开机」启动实例。
2. 在配置向导里勾选「实例以无卡模式开机：先只下载模型」；已经连过的实例，在「设置 → 远程 GPU → 云端配置」点「重新配置…」，勾选「无卡模式：只下载模型」，再点「开始下载模型」。软件不检查显卡，只下载并校验所选工作流的模型。文本编码器按 INT8 下载。
3. 看到「模型已就绪」后，到控制台关机，改用有卡模式开机。
4. 回到「设置 → 远程 GPU」，在「云端配置」点「重新配置…」，取消勾选「无卡模式」，点「配置并验收」。已下载的模型会直接复用，也不会再做一遍 SHA-256 校验，GPU 计费时间只花在安装运行环境、出图出片和自检上。

如果有卡模式下忘了取消勾选，软件只会重新核对模型，不会出错；在无卡模式下点「配置并验收」，会提示未检测到 GPU。

## 开机提示「该主机空闲GPU不足」

按量计费的实例关机后，显卡会让给其他用户。再开机时如果这台主机没有空卡，会弹出「该主机空闲GPU不足」。可以过一阵再试，也可以把实例克隆到同地区另一台有空卡的主机：把鼠标移到「更多」，点「克隆实例」，**勾选「数据盘」**（默认不勾，不勾模型不会跟过去），点「继续」，挑一台空闲 GPU 大于 0、可扩容不少于 50GB、CUDA 不低于 12.8 的主机，数据盘同样扩容 50GB，再「创建并开机」。RTX 4090 都没有空卡时可以选 vGPU-48GB（48GB 显存的 RTX 4090，价格稍高）。

克隆出来的是新实例，登录指令会变：在「设置 → 远程 GPU」点「连接 AutoDL 实例」重新连接，或者点原服务器的「修改」换成新的地址和端口。已下载的模型和安装进度都在数据盘上，点「配置并验收」会直接复用。原实例不用了可以在「更多」里释放，避免继续收数据盘费用。

## 配置时怎么知道没有卡住

「云端配置」会显示当前阶段已经进行了多久。安装运行环境时还会显示正在下载的软件包、已下载多少、速度和最近一次进展的时间。软件源慢的时候这一步可能要二三十分钟，只要「多久前有进展」还在变化就是在正常进行。超过 3 分钟没有任何进展时会出现提醒：可以再等几分钟；超过 15 分钟仍无变化，到 AutoDL 控制台关机止损，下次开机后点「重试配置并验收」，已下载的内容会复用。

## 已手动登记公钥的服务器

也可以使用已有的 Windows OpenSSH 私钥单独安装云端环境。

1. 在黑箱剧场打开「设置 → 远程 GPU」，点「手动添加 SSH 服务器」。填入控制台给出的主机、SSH 端口和用户名，选择已登记公钥对应的私钥文件；使用 SSH 默认密钥时可以留空。ComfyUI 端口默认是 8188。
2. 保存，点「在这台上出片」，在下方「云端配置」中选择工作流。默认安装 Qwen 素材出图和文武双全视频，另可选 Hybrid、仅素材出图，以及 SeedVR2 超分。
3. 点「配置并验收」。软件检查 GPU、驱动和数据盘，核对现有模型，显示还需要的磁盘空间。下载支持断点续传、备用来源和 SHA-256 校验。文武双全会按显卡选择文本编码器，RTX 40 系及更早的卡使用 INT8。
4. 等待验收素材出现在设置页。软件会检查工作流所需的节点和模型，先生成一张图。选了视频工作流时，它还会以这张图为参考生成约 4 秒的镜头，再通过 SSH 隧道取回并校验视频。仅素材模式显示验收图，超分选项会检查超分所需节点和模型。
5. 完成后，就可以在素材页或镜头页使用已安装的工作流，用完记得到 AutoDL 控制台关机。

## 配置后的默认自检

安装器会自动检查工作流节点和模型，实际生成一张素材图。选择视频工作流时，还会实际生成约 4 秒的镜头。软件取回验收文件并核对大小和 SHA-256，随后通过本机 SSH 隧道读取 ComfyUI 的显卡信息和任务队列。首次向导还会使用已保存的 DeepSeek 配置发送一句固定测试文本，按 API 用量计费。仅配置 GPU 且未设置 DeepSeek 时，报告会将文本生成列为跳过。

桌面软件保持打开时，离开设置页也会继续自检。结果保存在「设置 → 远程 GPU」，包含各项通过、跳过或需处理的原因。修复问题后可点「重新自检」复查连接和文本生成，已通过的素材生成和文件验收可直接复用。重新打开已有报告不会重复发送测试文本。使用「素材」出图或在「镜头」使用已安装的工作流出片时，需要保持实例开机。

## 中断后继续

安装包上传完成后，云端任务独立运行。关闭软件或电脑休眠后，再次打开同一服务器的设置页即可查看云端进度、取回成片。实例重启或安装失败时，点「重试配置并验收」会重新核对模型并继续。若云端端口已有可用的 ComfyUI，软件会先尝试直接验收；提示端口冲突时可在服务器设置里更换 ComfyUI 端口。

安装目录为数据盘的 `/root/autodl-tmp/blackbox/<ComfyUI端口>/`。其中 `setup.log` 记录安装过程，`comfy.log` 记录托管的 ComfyUI 服务。可复用放在 `/root/autodl-tmp/ComfyUI/models/` 对应子目录里、通过校验的模型。首次安装所需空间随工作流而变。使用 INT8 文本编码器时，公开版文武双全普通与接续工作流共用 7 个文件，合计 49.53 GiB，包括视频主模型、文本编码器、默认 LoRA、音频 VAE、视频 VAE、预览 VAE 和潜空间放大模型。Qwen 素材文生图与图生图共用另外 3 个文件，占 16.10 GiB。整套合计 65.63 GiB，首次安装还预留 14 GiB 给环境和临时文件。单独勾选 SeedVR2 超分会额外下载约 3.88 GiB 模型。

## 在另一台实例上复用

AutoDL 的「保存镜像」保存系统盘。此安装器把环境、插件、模型和进度文件放在数据盘。同地区换机时，可以关机后克隆实例并勾选「同时拷贝数据盘」，在新服务器设置里填写新的 SSH 连接信息并使用原 ComfyUI 端口。继续使用同一台实例时，普通关机后文件仍然保留。实例释放和迁移规则见 [AutoDL 镜像文档](https://www.autodl.com/docs/image/) 和 [同地区克隆文档](https://www.autodl.com/docs/migrate_instance_2/)。
