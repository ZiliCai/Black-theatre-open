# 模型下载

每个工作流需要的模型都列在下面：放到 ComfyUI 的 `models/` 下的哪个位置、多大、从哪里下载。

- 国内网络优先用「魔搭」或「HF 镜像」（hf-mirror.com）的链接；在 AutoDL 上也是这两个最快。
- 标了 **下载后改名** 的，来源处的文件名和工作流里用的不一样，下载后要改成「放到」那一列的名字。
- 这些模型的版权属于各自的作者，使用前请看原仓库的许可。

## 显卡和文本编码器

- 文武双全的两个视频工作流默认用 `qwen3vl_32b_minimax_h3_nvfp4_awq`（14.6 GB），只有 RTX 50 系显卡能发挥 FP4 的速度。
- 4090 等 40 系及更早的显卡，可以换成 `qwen3vl_32b_minimax_h3_int8_convrot`（25.3 GB）：远程出片时在设置 → 远程 GPU 的「模型替换」里把 nvfp4 换成 int8。
